Quick start
-----------
1. Copy .env.example to .env and set DEEPSEEK_API_KEY and FMP_API_KEY
2. pip install -r requirements.txt
3. python invest_bot_gui.py          (GUI)
   python global_screener.py         (CLI full scan)
   python invest_bot_launcher.py     (CLI menu)

Build exe: .\build_exe.ps1  →  dist\InvestBot.exe

See readme_en.txt or readme_zh.txt for complete details.
